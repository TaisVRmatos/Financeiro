COMO USAR
================================================================================

1. STREAMLIT (Recomendado)
   $ pip install -r requirements.txt
   $ streamlit run app.py
   → Abra http://localhost:8501

2. LINHA DE COMANDO
   $ python main.py matera.csv complementar.csv template.xlsx saida.xlsx
   $ python main.py --help

3. PYTHON SCRIPT
   from processor import process_integration, export_to_excel
   result = process_integration('m.csv', 'c.csv', 't.xlsx')
   export_to_excel(result, 'saida.xlsx')

4. DOCKER
   $ docker build -t integrador .
   $ docker run -p 8501:8501 integrador

5. TESTES
   $ pytest test_processor.py -v

================================================================================
ARQUIVOS PRINCIPAIS
================================================================================

🎨 APP.PY (Interface Streamlit)
  - Upload de 3 arquivos
  - Botão de consolidação
  - Visualização prévia dos dados
  - Download em Excel/CSV
  - Métricas de processamento

⚙️ PROCESSOR.PY (Lógica Principal)
  Funções:
  - normalize_doc()          → Normaliza documentos
  - read_matera()            → Lê fonte de verdade
  - read_complementar()      → Lê fonte complementar
  - read_template()          → Lê template Excel
  - merge_data()             → Consolida dados
  - fill_template()          → Preenche template
  - process_integration()    → Fluxo completo
  - export_to_excel()        → Exporta para Excel
  - export_to_bytes()        → Exporta para bytes

🖥️ MAIN.PY (Interface CLI)
  Opções:
  - matera (obrigatório)     → Arquivo Matera
  - complementar (obrigatório) → Arquivo complementar
  - template (obrigatório)   → Arquivo template
  - output (opcional)        → Caminho saída (padrão: consolidado.xlsx)
  - --verbose                → Exibe detalhes

✅ TEST_PROCESSOR.PY
  Classes de teste:
  - TestNormalizeDoc         → Testes de normalização
  - TestReadFiles            → Testes de leitura
  - TestMergeData            → Testes de merge
  - TestFillTemplate         → Testes de preenchimento
  - TestIntegration          → Testes de integração
  - TestDataQuality          → Testes de qualidade

================================================================================
REGRAS DE NEGÓCIO IMPLEMENTADAS
================================================================================

1. FONTE DE VERDADE
   → Dados do Matera sempre prevalecem

2. NORMALIZAÇÃO
   → Remove caracteres não numéricos
   → Exemplos:
     "4663656414"   → "4663656414"
     "4663656414."  → "4663656414"
     "4.663.656414" → "4663656414"

3. MERGE
   → Left join em Matera (preserva todos os registros)
   → Match por doc_normalized

4. PREENCHIMENTO
   → Matera > Complementar > "REVISAR"

5. SAÍDA
   → Respeita exatamente as colunas do template
   → 35 colunas obrigatórias
